🧮 Calculator App
Calculator App is a simple Android application developed using Java and XML layouts. The project demonstrates the fundamentals of Android application development by implementing a functional calculator with a clean and intuitive user interface.

Users can enter numbers and perform common arithmetic operations such as addition, subtraction, multiplication, and division. The application processes button interactions, performs calculations, and dynamically displays the result.

✨ Features
* ➕ Addition – Perform addition calculations.
* ➖ Subtraction – Subtract one value from another.
* ✖️ Multiplication – Perform multiplication operations.
* ➗ Division – Divide values and calculate the result.
* 🔢 Number Input – Enter numeric values through calculator buttons.
* 🧹 Clear Input – Clear the current calculation.
* 🧮 Real-Time Calculation – Update results based on user input.
* ⚠️ Input Handling – Handle calculator input appropriately.
* 🎨 XML UI Layout – Build the interface using XML layouts.
* ☕ Java Logic – Implement calculator operations and event handling using Java.
